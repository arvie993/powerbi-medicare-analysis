┌───────────────────────────────────────────────────────────────────────────────┐
│ KEY MEASURES - WHAT THEY MEAN                                                │
├───────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│ 💰 TOTAL COVERED CHARGES                                                     │
│    What: Amount hospitals BILLED to Medicare                                 │
│    Think: "Sticker price" before negotiation                                 │
│    Example: $100,000 billed (but Medicare pays much less)                    │
│                                                                               │
│ 💵 TOTAL MEDICARE PAYMENTS                                                   │
│    What: Amount Medicare ACTUALLY PAID                                       │
│    Think: Real cost to government                                            │
│    Example: $25,000 paid (75% discount from charges)                         │
│                                                                               │
│ 📊 AVERAGE PAYMENT PER DISCHARGE                                             │
│    What: Typical cost per patient                                            │
│    Think: Average price per hospitalization                                  │
│    Example: $15,000 = average cost per patient                               │
│    Use: Compare providers, identify expensive procedures                     │
│                                                                               │
│ ⚡ PAYMENT EFFICIENCY RATIO                                                  │
│    What: Payments as % of charges                                            │
│    Think: Negotiation effectiveness (LOWER = BETTER)                         │
│    Example: 25% = $25 paid per $100 billed                                   │
│    Target: <30% is good, <20% is excellent                                   │
│                                                                               │
│ 🏥 UNIQUE PROVIDERS COUNT                                                    │
│    What: Number of different hospitals in data                               │
│    Think: How many providers you're analyzing                                │
│    Use: Check filter results, validate coverage                              │
│                                                                               │

┌───────────────────────────────────────────────────────────────────────────────┐
│ UNDERSTANDING THE NUMBERS                                                    │
├───────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│ 💡 WHY ARE COVERED CHARGES SO HIGH?                                          │
│    Hospitals bill high "list prices" knowing Medicare will pay negotiated    │
│    rates that are 60-80% lower. It's like buying a car - the MSRP is high   │
│    but nobody pays full price.                                               │
│                                                                               │
│    Example:                                                                   │
│    • Hospital bills (Covered Charges): $100,000                              │
│    • Medicare pays (Actual Payment): $25,000                                 │
│    • Discount: 75% off billed amount                                         │
│                                                                               │
│ 💡 WHAT'S A GOOD EFFICIENCY RATIO?                                           │
│    Lower is better! It means the provider accepts less payment relative      │
│    to what they bill.                                                        │
│                                                                               │
│    Interpretation:                                                            │
│    • 15% = Excellent (pays $15 per $100 billed) ✅                           │
│    • 25% = Good (pays $25 per $100 billed) ✅                                │
│    • 35% = Average (pays $35 per $100 billed) ⚠️                             │
│    • 45% = Poor (pays $45 per $100 billed) ❌                                │
│                                                                               │
│ 💡 HOW TO COMPARE PROVIDERS FAIRLY?                                          │
│    Always compare "apples to apples":                                        │
│    ✅ Same procedure type (DRG)                                              │
│    ✅ Same severity level                                                    │
│    ✅ Similar patient volumes                                                │
│    ❌ Don't compare cardiac surgery to routine care                          │
│    ❌ Don't compare severe cases to minor cases                              │
│                                                                               │
│ 💡 WHAT'S THE DIFFERENCE BETWEEN MEASURES?                                   │
│    • Average Payment per Discharge = Measure (calculated on the fly)        │
│    • Payment Per Discharge = Column (pre-calculated per row)                │
│    Measures recalculate based on filters. Columns are static per row.       │
│                                                                               │

┌───────────────────────────────────────────────────────────────────────────────┐
│ DO's AND DON'Ts                                                               │
├───────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│ ✅ DO:                                                                        │
│   • Filter using dimension tables (Providers, DRG Medical Categories)        │
│   • Use measures for calculations (they update with filters)                 │
│   • Compare similar procedures/severity levels                               │
│   • Consider volume when looking at averages                                 │
│   • Use display names (Provider Name, not Provider ID)                       │
│                                                                               │
│ ❌ DON'T:                                                                     │
│   • Filter on hidden ID columns (use dimension tables instead)               │
│   • Compare different severity levels without noting it                      │
│   • Judge efficiency alone (consider complexity too)                         │
│   • Use averages with tiny sample sizes (<10 discharges)                     │
│   • Forget geographic/market context                                         │
│                                                                               │

┌───────────────────────────────────────────────────────────────────────────────┐
│ GLOSSARY - QUICK DEFINITIONS                                                 │
├───────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│ DRG = Diagnosis Related Group (procedure classification system)              │
│ HRR = Hospital Referral Region (healthcare market area)                      │
│ Discharge = Patient leaving hospital (end of stay)                           │
│ Covered Charges = Amount billed (before negotiation)                         │
│ Medicare Payments = Amount actually paid by Medicare                         │
│ Efficiency = Payment as % of charges (lower = better)                        │
│ Intensity = Cost/complexity level of service                                 │
│ MCC = Major Complication/Comorbidity (very sick)                             │
│ CC = Complication/Comorbidity (moderately sick)                              │
